UAMSWP List All Gravity Forms adds one page to a WordPress multisite network's Network Admin: a table of every Gravity Forms form on every site in the network, with a link to edit each form and links to the pages that embed it. It is for network administrators who need to know which forms exist and where they are used.

This wiki holds the documentation: a walkthrough, a task guide, the reference for the forms table, troubleshooting, and how the plugin works. The [README](https://github.com/UAMS-Web/uamswp-list-gravityforms#readme) keeps an overview, the requirements and installation.
